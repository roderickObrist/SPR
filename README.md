# Extensible Games CLI

Build a Python 3.11+ application using only the standard library. Support scissors-paper-rock against the computer.

## Design
The object representation will be:

### Game/Runtime
 - Name
 - State
 - Player 1
 - Player 2

### Player
 - Type
 - Strategy

### Persistance
 - save_state()
 - load_state()
